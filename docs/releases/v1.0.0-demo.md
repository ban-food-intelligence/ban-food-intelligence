# BAN Shop POS v1.0.0-demo

Android point-of-sale app of the BAN Food Intelligence prototype, ready to install without
Android Studio.

**What it is:** the Kotlin POS for the shop (Sell, Lots, Recall, Sync, Settings). Sales are stored
in SQLite first, signed with a key from the Android Keystore and synced to the Go API; recalled
lots are blocked, also offline.

**Install:** `adb install -r ban-shop-pos-v1.0.0-demo.apk` (or copy the file to the phone and
allow installing from this source). Android 8.0+.

**Connect to the server:** start the stack (`docker compose up -d --build`, then
`./scripts/demo-reset.sh`). The app uses `http://127.0.0.1:8080`:
- USB phone: `adb reverse tcp:8080 tcp:8080` (again after every reconnect).
- Emulator: Settings → Server → *Android emulator* (10.0.2.2).
This demo build only allows plain HTTP to the local addresses above (no LAN IP); build the debug
variant from source for Wi-Fi.

**Demo credentials:** supervisor PIN `246813` (recall stop unlock on the phone, starting recalls
on the dashboard). Demo value only.

**AI forecasts (Lots → Yield forecasts, dashboard *AI*):** studies A (production packages and
EKP) and B (butchery part weights) now come with an evaluation that holds up to questions:
5-fold rolling-origin cross-validation, 95 % block-bootstrap confidence intervals and
Diebold-Mariano tests against the baselines (the Ridge model roughly halves the error of the
historical mean, and the intervals do not overlap). Every prediction carries an 80 % conformal
interval (measured coverage 79-83 %), and an `anomaly` flag marks actual values outside the 98 %
band (0.14 false alarms per 100 normal orders). The phone shows the interval under each forecast
and an anomaly line when the flag is set. The training data is synthetic; details in
`docs/AI.md` and `ml-engine/ML_REPORT.md`.

**Not in this build:** invoice reading (OCR) is switched off, because the API key it needs is never
shipped inside an app. The row in *Lots* says so.

**Signing:** demo-only key, not a store key. SHA-256 of the signing certificate:
`2e0e87ad33e1c49b252fc1d315a3c9c8a775190c99eddb0519d6e366d14d5aef`.

If a phone had an older build installed, uninstall it first or run `./scripts/demo-reset.sh`:
the server pins each device's signing key and a reinstall creates a new key.
